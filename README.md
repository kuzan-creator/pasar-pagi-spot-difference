Pasar Pagi — Cari Bedanya! A complete, original spot the difference game set in an Indonesian morning market. Three levels — Lapak Buah (7 differences), Warung Kopi (8 differences) and Taman Bermain (9 differences) — each shows two near-identical pictures side by side. Click a difference (or move the crosshair with the arrow keys and press Enter) to mark it with a green ring on both panels; wrong clicks cost 5 seconds. A counter shows how many differences remain, hints are limited to 3 per level, and the timer gets shorter as the levels get harder. All art is drawn in code with canvas primitives and all sounds are synthesised with WebAudio — no images, fonts or sounds are loaded from the network.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. Keyboard: arrow keys move the crosshair, Enter checks a spot, H hint, R restart level, N next level, 1/2/3 switch level, M mute.
